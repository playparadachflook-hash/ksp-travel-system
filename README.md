# ระบบขออนุมัติไปราชการออนไลน์ โรงพยาบาลโคกศรีสุพรรณ (KSP Travel System)

ระบบบริหารจัดการคำขออนุมัติเดินทางไปราชการออนไลน์ พัฒนาด้วย **Node.js + Express + SQLite (better-sqlite3)** พร้อมปฏิทินการไปราชการ ระบบอนุมัติและมอบหมายงาน รายงานสรุปงบประมาณ และสร้างเอกสาร PDF ขนาด A4

## การติดตั้งและใช้งาน
```bash
npm install
cp .env.example .env
npm start
```

เปิดใช้งานได้ที่ `http://localhost:3534`
- บัญชีผู้ดูแลระบบเริ่มต้น: `admin` / `admin`
- บัญชีผู้ใช้ทั่วไปเริ่มต้น: `user` / `user`
